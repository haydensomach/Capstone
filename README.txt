analyzeVoiceMetrics performs the calculations of all metrics.  
calculateAllVoiceMetrics outputs values for all metrics.  
calculateHNR outputs a value for HNR.  
calculateJitter outputs a value for Jitter.  
calculateShimmer outputs a value for Shimmer.  
calculatePSDJitter outputs a value for the per-second harmonic band contribution perturbation.  
extractPoincareData reads in data and computes Poincare data to plot.  
calculatePoincare further groups data for Poincare plots.  
plotPoincare produces Poincare plots.  
plotROC produces ROC plots.  
DEMO records live audio as a .wav file and produces values for all metrics. All recordings taken with this function are saved in a new folder within the workspace.
